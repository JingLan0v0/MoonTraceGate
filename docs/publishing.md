# Release steps

Use JingLan0v0/tracegate 0.1.0 and the owner-supplied public MoonTraceGate URL.
Update moon.mod with the confirmed repository URL. Preserve history with a
normal push and verify Windows and Ubuntu jobs on its source commit. Inspect
the actual publisher ZIP, check the tracked source comparison and run a clean
extraction. Check formal Mooncakes success separately from preflight. Validate
the exact dependency from a fresh registry cache and run examples/library as
an independent installation. Record archive digest, file count and results.
Update installation docs and the one-page desktop submission with actual
URLs, required user actions and SHA-bound results.
